# Ushna Imran — portfolio

Static one-page portfolio built from the Figma file
`qNIx6bYZZ9ewdWayAdL57P` ("Ushna portfolio", node `2:28014`).

No framework, no build step. Open `index.html` or serve the folder.

```bash
python3 -m http.server 4321      # then http://127.0.0.1:4321
```

## Layout

```
index.html          markup (generated by tools/build_html.py)
css/style.css       all styling
js/main.js          social expand, case-study modals, video triggers
js/cases.json       slug -> case-study slice paths (written by tools/cases.py)
assets/img/         tiles, hero art, section bands
assets/video/       transcoded MP4 + WebM + poster frames
assets/fonts/       Satoshi (Fontshare, free for commercial use)
assets/case/        case-study slices, one folder per project
tools/              extraction + build scripts (not shipped to prod)
```

| Tiles | 347×238 (work), 347×378 (social), 7px gutter |

## Regenerating

```bash
python3 tools/extract.py      # render + download homepage assets from Figma
python3 tools/slice.py        # slice the ui/ux + social grids into tiles
python3 tools/build_html.py   # regenerate index.html
python3 tools/cases.py        # render + slice case studies -> js/cases.json
./tools/video.sh              # re-transcode source video
```

`tools/` needs a Figma token in `.figtok` (gitignored).

## Notes

- A tile only becomes clickable once its case study exists in `js/cases.json`.
  Missing ones render normally but do nothing, so nothing looks broken.
- Videos are transcoded from 94 MB of source to 8.4 MB total.
- Section body copy is still the Figma placeholder (it ends mid-sentence on a comma).
